# Python System Activity Logger

## Project Overview
This project is a simple Python-based system activity logger developed for cybersecurity learning and system monitoring practice.

## Features
- Timestamp logging
- Automatic log directory creation
- Exception handling
- Continuous activity monitoring
- Graceful shutdown handling

## Technologies Used
- Python
- Linux Environment

## Purpose
The project was created for educational purposes to improve understanding of logging systems, monitoring, and basic cybersecurity concepts.
